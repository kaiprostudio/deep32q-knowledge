F07: 存貨週轉效率同業對比 - 財務審計專家報告

📋 審計題目

存貨週轉天數與同業相比是否具備競爭優勢？整體營運週期 (Cash Cycle) 是否處於擴張狀態？

🎯 專家直斷

  • 核心結論：DIO 801天居中（華邦607/晶豪科795/愛普446）。DSO 103天為同業最差，CCC 647天居末。營運週期收縮改善中，但收款管理落後。
  • 風險評級：中
  • 數據時效：根據截至2025年最新公開數據

📊 診斷評級

DIO同業：愛普446 < 華邦607 < 晶豪科795 < 鈺創801天。DSO同業：愛普41 < 晶豪科60 < 華邦68 < 鈺創103天（最差）。CCC同業：愛普290 < 華邦512 < 晶豪科592 < 鈺創647天。DPO同業：華邦163 < 愛普197 < 晶豪科263 < 鈺創257天（供應商融資優勢）。鈺創CCC自2022年1,663天已大幅改善至647天（-61%），同業無此改善幅度。2026年營收暴增將加速分母放大，DIO有望降至300-400天追趕愛普。

🔍 答詢詳解

1. 存貨週轉效率階差

  • 核心重點：DIO 801天為同業末段（愛普446最佳），但改善幅度最大（1,980→801天，-60%，同業-7%~-62%）。庫存去化力度強，但起點極高。

  • 深度見解：高DIO結構原因：2022年崩跌時備料過度（存貨/營收70%），且為Fabless模式需較高安全庫存。華邦有自有晶圓廠排程可控，愛普以IP授權庫存輕。

2. 應收帳款同業劣勢

  • 核心重點：DSO 103天遠遜同業（愛普41天），差距151%。主因客戶結構：鈺創客戶為中小型網通/工控客戶，付款條件較差。

  • 深度見解：結構性問題短期難解。但單季DSO已降至59天（Q4推算），若2026年大客戶增加有助DSO降至70-80天，將是CFO轉正的關鍵助力。

3. 營運週期趨勢

  • 核心重點：CCC 647天（同業愛普290/華邦512/晶豪科592）。但改善幅度-61%為同業之最。若2026年DIO 400+DSO 70-DPO 250=220天。

  • 深度見解：1,663天CCC屬異常狀態。2026年營收暴增將快速稀釋各項天數。預估2026Q2-Q3 CCC降至250-350天，CFO有望在此區間轉正。

💡 專家評析（多空雙向分析 Mandate）

🔴 空方觀點（利空風險）

  1. DSO 103天為同業最差，收款壓力持續：即使營收暴增，應收帳款管理制度落後同業（愛普41天、華邦68天）。若新客戶的付款條件未改善，DSO僅能靠分母放大被動下降，而非主動效率提升。
  2. DIO改善來自營收分母放大而非庫存去化：存貨僅從2.54B微增至2.70B（+6.4%），DIO腰斬主因Q4營收暴增至1.6B。若2026年營收結構性提升，DIO可快速改善，但若營收趨緩，庫存去化可能重現僵局。

🟢 多方觀點（機會可能性）

  1. CCC從1,663天降至647天，改善幅度業界少見：兩年內現金循環縮短1,016天，顯示存貨管理發生質變。若2026年維持此趨勢，CCC有望降至300天以內，現金流從流出轉為流入。
  2. DPO 257天展現供應商議價優勢：付款天數為同業前段（僅次於晶豪科263天），供應商願意承擔8.5個月帳期代表對鈺創信賴度高。這項優勢可緩解AR端的收款壓力。

⚖️ 綜合權衡

鈺創營運週期效率在同業中居後段，但改善速度為同業之最。2026年營收爆發將提供進一步改善的催油門效應。DSO和DIO兩大軟肋均處於改善軌道，現金循環轉正時間點為營運體質轉折的關鍵指標。
