🌾 黃豆追蹤日誌 — 2026-07-09

📌 本日敘事錨點
美伊衝突升溫推升能源成本，但美國黃豆作物進度優於均值，供給壓力有限

本日黃豆市場受兩股力量拉鋸：一方面，川普宣布美伊停火結束，國際油價飆漲逾7%，推升運輸與壓榨成本，理論上利多農產品價格；另一方面，USDA 7/6作物進度報告顯示，美國黃豆開花率達34%，優於五年均值，作物狀況良好，供給前景樂觀，壓制了天氣溢價。此外，中國農業部預測2026-27年黃豆進口量將從1.12億噸降至8,260萬噸，長期需求成長放缓的預期也對價格形成壓力。

來源：Barchart (2026-07-08)、Agriculture.com (2026-07-06)

📰 重點追蹤

1. 美國作物進度優於均值，供給壓力有限

  • 事實是什麼？ USDA 7/6作物進度報告顯示，美國18州黃豆開花率達34%，優於五年均值；作物狀況方面，優良率與去年同期大致持平
  • 為什麼發生？ 中西部天氣條件整體有利，威斯康辛州7月初氣溫低於正常，土壤水分適中；但西部野火風險升高、季風延遲可能影響部分區域
  • 傳導鏈：良好作物進度 → 壓低天氣溢價 → 限制價格上漲空間 → 但若7月中高溫持續可能引發熱害擔憂
  • 接下來看什麼？ 7月中天氣預報、USDA WASDE月報（8月）、Export Sales週報（7/10公布）

來源：Agriculture.com (2026-07-06)、Crops and Soils Extension (2026-07-02)

2. 中國長期進口需求預測下修

  • 事實是什麼？ 中國農業部預測2026-27年黃豆進口量將從2025年創紀錄的1.12億噸降至8,260萬噸，抹去過去十年的進口成長
  • 為什麼發生？ 健康意識提升減少食用油消費、養殖戶減少豆粕使用、國內黃豆產量擴增（2026-27年預估2,020萬噸）
  • 傳導鏈：中國需求成長放緩 → 巴西出口供過於求 → 壓低全球黃豆價格 → 但低價反而刺激需求回升（歷史經驗）
  • 接下來看什麼？ 中國實際進口數據（月度海關）、巴西種植面積、美中貿易協議後續

來源：World Grain (2026-07)、CZ app (2026-07)

3. 美中貿易協議帶動採購回升，但未達戰前水準

  • 事實是什麼？ 中國在貿易協議後恢復採購美國黃豆，但實際採購量仍遠低於貿易戰前水準；2025年離岸季（10-3月）採購量因協議而回升
  • 為什麼發生？ 川普政府與中國達成貿易協議，中國承諾恢復採購美國農產品；但巴西供應持續擴張，中國對美豆依賴度已大幅降低
  • 傳導鏈：貿易協議 → 短期採購回升利多美豆 → 但長期巴西競爭優勢不變 → 美豆出口前景仍面臨結構性壓力
  • 接下來看什麼？ 中國月度美豆採購量、巴西2026/27種植進度

來源：Investigate Midwest (2026-07-01)

4. 能源成本飆升對壓榨產業的影響

  • 事實是什麼？ 川普宣布美伊停火結束，國際油價單日飆漲逾7%，創兩週新高
  • 為什麼發生？ 荷姆茲海峽航運風險升高，原油供應鏈受威脅
  • 傳導鏈：油價飆漲 → 壓榨與運輸成本上升 → 大豆油期貨上漲（7/8漲205-260點） → 但豆粕期貨下跌3.9-6.3美元 → 綜合壓榨利潤受壓縮
  • 接下來看什麼？ 油價走勢、荷姆茲海峽航運安全、OPEC+產量決策

來源：Barchart (2026-07-08)

- 中國貿易協議後恢復採購美豆
- 西部野火風險與季風延遲可能影響部分作物
