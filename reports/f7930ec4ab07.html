🥇 基本面分析

週末兩階段發展對黃金的影響

第一階段（伊朗攻擊→黃金看漲）：
- 8/1 伊朗攻擊多艘油輪 → 荷姆茲海峽緊張升級 → 避險需求理論上應推升金價
- InvestorsHub 8/2 頭條「Gold rises above $4,130 as geopolitical uncertainty supports safe-haven demand」

第二階段（Trump 取消打擊→黃金漲幅被壓縮）：
- 8/2 Trump 取消打擊 + 和平 MOU → 地緣風險溢價消退
- GC=F 從開盤 $4,135 回落至 $4,107 → 市場對和平前景定價
- +0.36% 漲幅極為克制——若無和平訊號，黃金可能已漲至 $4,150-$4,200

利多因素

  • 🔥 伊朗局勢未完全平息：雖有和平 MOU 但尚未簽署，荷姆茲仍受限，油輪攻擊仍在發生
  • 💲 Fed 內部分裂持續：3 票反對的信任裂痕未癒合，結構性利多黃金
  • 📈 油價下跌緩解通膨＝Fed 更可能降息＝黃金利多：看似矛盾但邏輯成立——油價降 → 通膨降 → Fed 降息空間大 → 黃金機會成本降
  • 📈 4,000 心理關卡堅實：多次測試守住

利空因素

  • 📉 戰爭溢價消退是最大利空：Trump 取消打擊直接消除了短期內全面衝突的風險
  • 📉 和平 MOU 若簽署→金價可能進一步回調：荷姆茲重開 → 油價續跌 → 通膨預期下降 → 黃金避險需求減少
  • 📉 美股風險偏好回升：S&P 期貨 +0.40%，資金可能從黃金回流股市
  • 📉 2026 迄今仍從 5,318 高點回檔約 22%：長期趨勢未扭轉
  • 📉 12 月合約從 $4,135 開盤回落：技術面顯示「開高走低」

🔮 短期展望

  1. 週一開盤預期：溫和偏弱 📉：Trump 和平訊號壓制避險需求。12 月合約可能在 $4,080-$4,120 區間震盪。若和平 MOU 正式簽署 → 可能回測 $4,050-$4,080
  2. 關鍵情境分析：
    - 🟢 MOU 簽署失敗／伊朗再攻擊 → 黃金 $4,150-$4,200
    - 🟡 MOU 談判持續但無結論 → 黃金 $4,080-$4,130 震盪
    - 🔴 MOU 正式簽署 + 荷姆茲重開 → 黃金可能回調至 $3,980-$4,050
  3. $4,100 為多空分水嶺：若站穩 $4,100 則維持偏多格局；跌破則短期偏空
  4. Fed 官員本週發言密切關注：若 Fed 因油價下跌而釋放更鴿派訊號 → 可能抵消和平利空
  5. 八月流動性偏低：波動可能放大
  6. 策略觀點：從「強烈看多」修正為「中性偏多」。戰爭溢價消退是實質利空，但 Fed 降息預期升溫 + 4,000 支撐堅實提供下檔保護。$4,080 以下可考慮分批布局，$4,150 以上建議觀望等待 MOU 結果
