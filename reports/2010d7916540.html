🪙 基本面分析

週末兩階段發展對白銀的影響

第一階段（伊朗攻擊→貴金屬全面看漲）：
- 8/1 伊朗攻擊油輪 → 避險需求推升貴金屬
- 黃金電子盤一度上漲至 $4,130+，白銀跟漲至 $60.300

第二階段（Trump 取消打擊→漲幅被壓縮）：
- 8/2 Trump 取消打擊 + 和平 MOU → 地緣風險溢價消退
- 白銀從 $60.300 高點回落至 $59.108，但跌幅不如黃金明顯（白銀 +0.80% vs 黃金 +0.36%）
- 白銀表現優於黃金——反映工業需求預期改善（油價下跌利多工業）

利多因素

  • 📈 油價暴跌是工業白銀的重大利多：布蘭特 -6.28% 至 $82.41 → 製造成本下降 → 工業需求預期改善。白銀約 50% 需求來自工業用途（太陽能、電子、醫療）
  • 📈 太陽能產業長期利多增強：油價下跌不影響再生能源長期趨勢，能源轉型仍是白銀需求核心驅動力
  • 📈 礦業活動持續活躍：Silver X 擴充紅銀鑽探 5 倍至 6,650 米、Aftermath Silver 啟動 Berenguela 鑽探、Avino Q2 產量公布、Purecore 完成第一階段探勘
  • 📈 黃金白銀比率改善中：4,107 / 59.108 ≈ 69.5x，較 7/31 的 70.3x 下降，白銀相對強勢

利空因素

  • 📉 $60 再度測試失敗：盤中觸及 $60.300 但迅速回落至 $59.108，$60 仍是沉重天花板
  • 📉 戰爭溢價消退：若和平 MOU 簽署，貴金屬板塊整體承壓
  • 📉 Fed 高利率持續：3.50-3.75% 對無孳息資產不利
  • 📉 7 月月線跌 3.17%：中期趨勢仍未扭轉

🔮 短期展望

  1. 週一預期：$58.50-$60.00 區間震盪：油價暴跌利多工業需求（支撐白銀），但戰爭溢價消退利空貴金屬（壓制白銀）。兩股力量拉鋸下，白銀可能在 $59 附近整理
  2. 白銀表現優於黃金的邏輯：油價下跌 → 製造業成本降 → 工業金屬利多。若此趨勢持續，黃金白銀比率可能進一步降至 68x 以下——這是白銀跑贏黃金的強烈訊號
  3. 關鍵情境分析：
    - 🟢 MOU 簽署 + 油價穩在 $80 以下 → 白銀受益最大，可能挑戰 $60.50-$62（工業需求利多 > 避險需求利空）
    - 🟡 MOU 談判膠著 → 白銀 $58-$60 震盪
    - 🔴 MOU 破裂 + 伊朗再攻擊 → 白銀短期可能飆至 $62+，但隨後工業需求擔憂浮現
  4. $60 仍是關鍵阻力：連續多次測試未能站穩。若本週在工業需求利多加持下突破 $60，將確認多頭格局
  5. 策略觀點：中性偏多。白銀的獨特優勢在於它同時受益於「和平紅利」（工業成本下降）和「避險需求」（地緣仍有風險）。$58 以下可考慮分批布局。突破 $60 且站穩 → 目標 $62-$64。跌破 $57 → 觀望
