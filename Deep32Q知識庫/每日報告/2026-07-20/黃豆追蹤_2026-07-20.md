# 🌾 黃豆追蹤日誌 — 2026-07-20

📌 本日敘事錨點
**USDA 7 月 WASDE 報告維持 2026/27 年度黃豆價格預測 $11.40/bu，美國產量上修至創紀錄 44.75 億蒲式耳，但中西部天氣改善預期壓制短線溢價**。市場在 USDA 報告後短暫反彈，但隨即因天氣預報轉為溫和而回落。本日焦點：(1) 美國黃豆產量上修至歷史新高；(2) 中國需求預期上修至 1.08 億噸；(3) 中西部天氣改善降低供給風險溢價；(4) 全球期末存貨下修 0.7 百萬噸至 1.242 億噸。來源：USDA WASDE (2026-07)、WorldPerspectives (2026-07-15)、FarmProgress (2026-07-15)。

📰 重點追蹤（報告主體）

### 1. 🇺🇸 美國黃豆產量上修至創紀錄 44.75 億蒲式耳
- **事實是什麼？** USDA 7 月 WASDE 報告將 2026/27 年度美國黃豆產量上修至 44.75 億蒲式耳，較上月增加 4,000 萬蒲式耳，創歷史新高。收穫面積上修 70 萬英畝至 8,440 萬英畝，單產維持 53.0 蒲式耳/英畝。
- **為什麼發生？** 種植面積擴大超出預期，反映農民在高價激勵下增加播種。儘管單產未變，面積增加直接推升總產量。
- **傳導鏈**：產量增加 → 美國供給寬鬆 → 壓制期貨價格 → 但中國需求同步增加 → 部分抵消供給壓力。
- **接下來看什麼？** 8 月 WASDE 單產修正（關鍵）、中西部結莢期天氣、最終收穫面積確認。
- **來源**：USDA WASDE (2026-07)、BiomassMagazine (2026-07-15)、CIHedging (2026-07-15)。

### 2. 🇨🇳 中國黃豆進口預期上修至 1.08 億噸
- **事實是什麼？** USDA FAS 上修中國 2026/27 年度黃豆進口預測至 1.08 億噸，反映中國壓榨需求強勁。中國與阿爾及利亞的進口預測均上修。
- **為什麼發生？** 中國豬肉養殖復甦帶動豆粕需求，壓榨利潤改善刺激進口採購。中國持續從巴西採購大量黃豆。
- **傳導鏈**：中國需求增加 → 全球出口量增加 → 支撐價格底部 → 但美國產量上修限制上行空間。
- **接下來看什麼？** 中國採購節奏、巴西出口競爭、美中貿易政策變化。
- **來源**：USDA WASDE (2026-07)、SoyGrowers (2026-07-15)、WorldPerspectives (2026-07-15)。

### 3. 🌤️ 中西部天氣改善：供給風險溢價消退
- **事實是什麼？** 美國中西部天氣預報轉為較為溫和，結莢期降水充足，降低供給中斷風險。黃豆期貨在 USDA 報告後短暫反彈，但隨即因天氣改善預期而回落至 $12/bu 以下。
- **為什麼發生？** 7 月中旬中西部進入結莢關鍵期，適時降水有利於單產。天氣模型顯示未來兩週無極端高溫或乾旱威脅。
- **傳導鏈**：天氣改善 → 單產風險降低 → 天氣溢價消退 → 期貨價格承壓。
- **接下來看什麼？** 未來一週天氣模型更新、作物進度報告、8 月單產預估。
- **來源**：ThePigsite (2026-07-17)、FarmProgress (2026-07-15)。

### 4. 🌍 全球期末存貨下修 0.7 百萬噸至 1.242 億噸
- **事實是什麼？** 2026/27 年度全球黃豆期末存貨下修 0.7 百萬噸至 1.242 億噸，主要因巴西存貨減少。美國與巴西出口均上修，俄羅斯出口因供給減少而下修。
- **為什麼發生？** 巴西存貨下降反映其國內壓榨需求強勁，壓縮出口能力。全球需求同步增加，抵消部分美國產量上修壓力。
- **傳導鏈**：全球存貨微降 → 供需格局偏緊 → 但美國產量創紀錄限制價格上行 → 價格在 $11-12 區間震盪。
- **接下來看什麼？** 巴西播種進度、南美天氣預報、全球壓榨需求變化。
- **來源**：USDA WASDE (2026-07)、RoachAg (2026-07-15)、SouthernAgToday (2026-07-15)。
