# 黃豆追蹤 2026-07-02（週四）

## 8 項追蹤指標

### 1. USDA 報告影響（6/30 Acreage & Grain Stocks）
- **已播種面積**：85.365M acres（年增 ~5%，近六年高）
- **6/1 存貨**：1.061B bu（年增 ~5%，高於預估）
- 結構意義：**面積 + 庫存雙增**，2026/27 供給壓力明確
- 📊 無重大變化，報告已 fully priced in

### 2. 美元與匯率
- DXY 101.42（觸 15M 高 101.6 後回落）
- Warsh 通膨降溫發言略緩美元漲勢，但年內升息預期仍支撐美元
- 📉 **偏空**：美元強勢壓制美豆出口競爭力，尤其巴西出口持續強勁

### 3. 中國需求
- 5 月川習峰會後市場持續關注中國是否回補美豆採購
- 截至目前無新增大額採購公告
- 📊 **中性偏空**：巴西出口競爭 + 匯率不利，中國回補動能有限

### 4. 出口檢驗
- 美國出口檢驗數據未見連續回升
- 📊 **中性**：出口需求維持常規水平，無超預期信號

### 5. 天氣與種植進度
- 中西部本週持續高溫，可能對大豆作物造成壓力
- 但預報顯示本週晚些時候將轉涼
- 📈 **短線偏多**：天氣壓力提供短線溢價，但若降雨及時利多有限

### 6. 壓榨與生質燃料需求
- 美國壓榨需求維持穩定
- 生質燃料政策面無新增重大變化
- 📊 **中性**：需求端穩定但無增量

### 7. 能源與肥料成本
- 油價持續回落（WTI $68.11），Hormuz 通航改善降低運輸成本
- 肥料成本壓力緩解，對農民種植成本偏正面
- 📊 **中性偏多**：成本面改善，但對期貨價格影響間接

### 8. 巴西出口競爭
- 巴西出口持續強勁，為美豆最大競爭壓力
- 巴西豐收季尚未結束，短期供給充裕
- 📉 **偏空**：巴西低價出口持續壓縮美豆出口空間

## 結論
黃豆在 USDA 報告利空出盡後進入 **「短線反彈、中期偏空整理」** 的格局：
- 短線反彈由 corn/wheat 聯動 + 天氣壓力 + 美元觸高回落驅動；
- 中期壓力來自面積擴增 + 庫存上升 + 巴西出口競爭 + 美元強勢；
- 7 月天氣炒作窗口仍在，但需持續高溫才能提供有效溢價；
- 週四 Nonfarm 數據若偏弱 → 美元回落 → 對黃豆短線偏正面。
